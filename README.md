# QuickBite - Food Delivery Website

A modern, responsive food delivery website built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 🍔 Interactive menu with 8 food items
- 🛒 Shopping cart with add/remove/update quantity functionality
- 📱 Fully responsive design (mobile-first)
- ⚡ Fast delivery hero section
- 👨‍🍳 Features showcase
- 📞 Contact information section
- 🎨 Modern orange/amber color scheme with emoji icons

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React** (Client Components)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

## Project Structure

```
├── app/
│   ├── page.tsx          # Main page with all sections
│   ├── layout.tsx        # Root layout
│   └── globals.css       # Global styles
├── components/
│   ├── Button.tsx        # Reusable button component
│   └── Card.tsx          # Reusable card component
└── public/               # Static assets
```
